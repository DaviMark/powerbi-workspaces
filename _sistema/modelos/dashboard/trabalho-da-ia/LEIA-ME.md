# trabalho-da-ia/

**Esta pasta é da IA.** Você não precisa abrir nem editar nada aqui — peça mudanças à IA no chat.

| Arquivo | O que é |
|---|---|
| `desenho.md` | o que a IA propôs a partir do seu pedido: modelo, métricas, páginas, decisões (Gate 1) |
| `conferencia.md` | números esperados × números do Power BI (Gate 2) |
| `dicionario.md` | todas as tabelas, colunas e medidas (gerado) |
| `historico.md` | o que mudou em cada versão |
| `sql/` | uma consulta por tabela do modelo |
| `ficha.toml` | dono, status, conexão e classificação do dashboard |
