O mapa do repositório

A skill resume todos os dashboards num mapa. Para responder sobre um dashboard, a IA lê o mapa, não centenas de arquivos.

Exemplo: o dashboard Aging de Títulos, que vem no repositório

Lendo todos os arquivos
66.000 tokens
Lendo o mapa
1.200 tokens

Valores do exemplo. Nos seus dashboards, os números mudam conforme o tamanho de cada projeto; a proporção costuma ser parecida. Menos leitura significa respostas mais rápidas e mais baratas.

Começar

Quatro passos.

1

Instale

Power BI Desktop, VS Code com uma IA (Copilot, Claude Code, Cursor ou Codex), Python 3.11+ e Git. Clone o repositório numa pasta curta, como C:\pbw: o Power BI Desktop não abre caminhos com 260 caracteres ou mais.

2

Instale a skill

Na pasta do repositório, no terminal do VS Code:

..\powerbi-architect\install\install.ps1 -Target .
3

Crie a identidade da empresa

Renomeie identidade-visual/nome-da-empresa, coloque o material da marca e peça à IA: crie a identidade visual da empresa.

4

Peça o primeiro dashboard

Duplique a pasta-modelo em dashboards, troque os nomes, preencha o pedido e diga à IA:

crie o dashboard aging-de-titulos

Segurança

Feito para empresas.

Sem dados

O repositório guarda estrutura, nunca linhas de dados. Arquivos com dados são bloqueados.

Sem senhas

O Power BI guarda as credenciais. O repositório só tem o endereço do banco.

Sem rede

As ferramentas rodam no seu computador, sem enviar nada para fora.

Com aprovação

A IA nunca publica sozinha. Desenho e números passam por você.
